ยิงแอดสำเร็จรูป

ยังไม่ได้ตั้งค่า
มีแอดที่เลยเวลาเผยแพร่แล้วแต่ยังไม่ได้เปิด (ตอนนั้นโปรแกรมถูกปิดอยู่)

1. เชื่อมต่อ Facebook

วิธีสร้าง Token แบบไม่หมดอายุ (ทำครั้งเดียว)
  1. สร้างแอปที่ developers.facebook.com → My Apps → Create App → เลือกประเภท Business แล้วผูกกับ Business Manager ของคุณ (ตั้งชื่ออะไรก็ได้ เช่น AdShooter)
  2. ไปที่ business.facebook.com → การตั้งค่าธุรกิจ → ผู้ใช้ → ผู้ใช้ระบบ (System users) → เพิ่ม → ตั้งชื่อ บทบาท ผู้ดูแล (Admin)
  3. ที่ผู้ใช้ระบบนั้น กด กำหนดสินทรัพย์ (Assign assets): เพิ่ม บัญชีโฆษณา (ให้สิทธิ์ควบคุมเต็ม) และ เพจ (ให้สิทธิ์ควบคุมเต็ม) และ แอป ที่สร้างในข้อ 1
  4. กด สร้างโทเค็นใหม่ (Generate new token) → เลือกแอป → วันหมดอายุเลือก ไม่มีวันหมดอายุ (Never)
  5. ติ๊กสิทธิ์: ads_management, ads_read, business_management, pages_show_list, pages_read_engagement, pages_manage_ads → สร้าง แล้วคัดลอก Token มาวางช่องด้านบน

ชื่อเมนูใน Facebook อาจต่างจากนี้เล็กน้อยตามเวอร์ชันหน้าจอ Token เก็บไว้ในเบราว์เซอร์บนเครื่องนี้เท่านั้น อย่าส่งไฟล์นี้หลังใส่ Token ให้คนอื่น และอย่าแชร์ Token ให้ใคร

2. เลือกบัญชี / แคมเปญ / ชุดโฆษณาหลัก

3. แอดต้นแบบ (ใช้ดึงเทมเพลตการสนทนา)

เลือกแอดสักตัวในชุดโฆษณานี้ที่คุณเคยสร้างเองโดยใช้เทมเพลต “เริ่มการสนทนา 22/10/2026” และปุ่มส่งข้อความ Messenger โปรแกรมจะคัดลอกข้อความทักทาย คำถามอัตโนมัติ และปุ่ม ไปใช้กับแอดใหม่ทุกตัว

แอดที่จะยิงรอบนี้

การเผยแพร่ (ใช้กับทุกแอดในรอบนี้)

แอดจะถูกสร้างไว้แบบ ปิด ทันที แล้วโปรแกรมจะกดเปิดให้เมื่อถึงเวลา — ต้องเปิดหน้านี้ทิ้งไว้และคอมพิวเตอร์ต้องไม่หลับ จนถึงเวลานั้น

รอเผยแพร่ตามเวลา

จัดการแอดในชุดโฆษณา

ชุดโฆษณามีแอดได้สูงสุด 50 ตัว (นับรวมแอดที่ปิดอยู่ ไม่นับแอดที่เก็บถาวรแล้ว)
เลือกแอดที่เก่ากว่า วัน
แอดที่เก็บถาวรแล้วจะหยุดทำงาน และ แก้ไขหรือกู้คืนกลับมาไม่ได้ (ยังดูสถิติย้อนหลังได้ใน Ads Manager)
